# Rahul Harod — Academic Portfolio

Personal academic portfolio website for Dr. Rahul Harod, Ph.D. (Civil Engineering, Remote Sensing), IIT Bombay.

## Deployment on GitHub Pages

1. Create a new GitHub repository named: `rahul-harod.github.io`
2. Upload all files maintaining the folder structure
3. Go to **Settings → Pages → Source: Deploy from branch → main → / (root)**
4. Your site will be live at: `https://rahul-harod.github.io`

## Structure

```
rahul-harod-portfolio/
├── index.html              # Welcome/Home page
├── research.html           # Research interests & PhD work
├── publications.html       # All publications
├── teaching.html           # Teaching philosophy & experience
├── awards.html             # Awards & Recognition
├── education.html          # Education & Experience timeline
├── contact.html            # Contact page
├── css/
│   └── style.css           # Main stylesheet (shared across all pages)
├── js/
│   └── main.js             # JavaScript (active nav, smooth scroll, mobile menu)
└── README.md               # This file
```

## Pages

- `index.html` — Home/Welcome with hero, quick stats, bio, and announcements
- `research.html` — Research interests and PhD thesis summary
- `publications.html` — Journal articles, conference proceedings, and abstracts
- `teaching.html` — Teaching philosophy, TA experience, and course list
- `awards.html` — PMRF, GATE achievements, and other recognition
- `education.html` — Education timeline, experience, technical skills
- `contact.html` — Contact information and academic profile links

## Tech Stack

- Pure HTML5 + CSS3 (no frameworks)
- Vanilla JavaScript (no libraries)
- Google Fonts: Merriweather + Source Sans Pro
- Mobile responsive via CSS flexbox and grid
- Ready for GitHub Pages (no build step required)
